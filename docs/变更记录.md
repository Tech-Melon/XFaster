# Tech Melon XFaster 变更记录

---

### 0.5.31 — 2026-08-03

- **功能**：弹窗 / 设置页支持中英文切换  
  - 右上角单按钮 `EN` / `中`，写入 `settings.uiLang`（默认中文）  
  - 搜图角标、系统右键「谷歌识图」菜单随语言更新  
  - `manifest` 增加 `_locales`（zh_CN / en）商店名与描述  

### 0.5.30 — 2026-07-30

- **修复**：监控列表编辑态（确认勾 / 取消叉 / 输入框）仍会跳转 X  
  - 根因：嵌套控件「完全放行」后，`<a href=x.com>` 的默认导航仍会触发  
  - 改为：命中嵌套控件时 **只 `preventDefault`**（拦跳转），**不 `stopPropagation`**（页面逻辑可跑）  
  - 编辑态：链接内出现 `input` / `contenteditable` 时整段交给页面  
  - 扩大识别：Check / Cancel / cursor-pointer 小图标等  

### 0.5.29 — 2026-07-30

- **修复**：外站 X 链接内部的嵌套控件（编辑笔 / 删除等）被误拦并打开 X  
  - 典型：监控列表把 `IconEdit` 放在 `a[href=x.com/user]` 内，点编辑却跳 X  
  - `link-observer` + `window-open-hook` 识别嵌套交互控件后放行，交给页面处理  

### 0.5.28 — 2026-07-29

- 搜图按钮：滚轮/页面滚动时**立刻隐藏**，不再跟滚位移；静止后重新瞄准  

### 0.5.27 — 2026-07-29

- 识图小窗单例复用加固：`session` 记住 window/tab，SW 回收后仍尽量 `tabs.update` 同一窗  
- 新标签模式也尽量复用上次识图标签  

### 0.5.26 — 2026-07-29

- 搜图按钮：同一张图上移动光标时**位置不变**；仅切换到另一张图才重新定位  

### 0.5.25 — 2026-07-29

- 识图小窗宽度改为 **700×800**（约 560 宽时 Lens 底栏易出横向滚动条挡内容）  

### 0.5.24 — 2026-07-29

- **搜图按钮跟手**：移动光标不再立刻消失；再次静止后按钮挪到新光标旁  
- 按钮更大、保留约 14s；离开图片有宽限期  
- 识图小窗强制尺寸（创建后再 `update`）  

### 0.5.23 — 2026-07-29

- **改善识图触发**：默认不再拦截系统右键（可另存为/复制图片）  
  - 默认：瞄准后点浮动「搜图」按钮  
  - 可选：Alt+右键；或旧版拦截左/右键  
  - 系统右键菜单增加「谷歌识图（XFaster）」项（`contextMenus`）  

### 0.5.22 — 2026-07-29

- **新功能**：可选谷歌识图（与打开 X 加速隔离）  
  - 弹窗一键开关；设置页配置静止阈值、最小尺寸、触发键、小窗/新标签、Lens/经典搜图  
  - 鼠标静止后瞄准图片（描边）；默认右键触发；单例小弹窗打开 Google Lens  
  - 仅支持 `http(s)` 图 URL（blob/data 暂不支持）；需站点授权后注入  

### 0.5.21 — 2026-07-29

- **修复**：域名误判——把 `*x.com`（如 `somethingx.com`）文本/属性中的子串 `x.com` 当成真 X 链接  
- 文本抽取正则增加主机前后边界（lookbehind/lookahead）；同步加固 `window.open` 兜底匹配  

### 0.5.20 — 2026-07-26

- **修复**：X 站内侧栏（主页/通知/聊天等）点不动——外站拦截钩子不再在 x.com/twitter.com 运行  
- 授权后注入跳过 X 标签，避免把外站拦截脚本注入站内  

### 0.5.19 — 2026-07-26

- MAIN 拦截 `a[target=_blank]`、程序化 `a.click()`  
- content 脚本 `all_frames` + `match_about_blank`，增强 iframe 场景  

### 0.5.18 — 2026-07-26

- **修复**：无 X 标签时同时打开 home + 推文（去掉打开路径上的 ensureWarmTab(home)）  
- 全局创建锁；pointerdown 更早拦截  

### 0.5.17 — 2026-07-26

- 弹窗不因 GET_STATUS 卡住；授权按钮始终可点  
- 请求超时与权限/状态分离刷新  

### 0.5.16 — 2026-07-26

- **修复**：`permissions.js` 块注释中 `*/` 导致 `Unexpected token '*'`，SW 注册失败（status 15）  

### 0.5.13–0.5.15 — 2026-07-26

- 弹窗站点授权：一键全站 / 授权当前站  
- 授权后向已开标签注入 content 脚本  
- 修复授权 UI 卡死、context invalidated 处理  

### 0.5.11–0.5.12 — 2026-07-26

- 必需 host 收窄为 X 相关；全网改为 optional  
- 增加 activeTab  
- 冷标签合并时序优化，减轻闪屏  

### 0.5.8–0.5.10 — 2026-07-26

- 导航捕获 window.open / 新标签到 X  
- 闲置热壳只切页不导航的修复  
- 伪链接识别增强  

### 0.5.6–0.5.7
