# XFaster 项目文档规范

## 1. 文档分层

| 层级 | 路径 | 读者 | 职责 |
|------|------|------|------|
| 入口 | `README.md` | 用户/开发 | 是什么、安装、权限、版本摘要 |
| Agent | `CLAUDE.md` | Claude | 铁律、默认、禁止项 |
| 专题 | `docs/*.md` | 开发/用户 | 使用、设计、变更、规范 |
| 商店 | 外部 `DOC\`（可选） | 上架 | 文案、隐私、审核 |

## 2. 更新义务

| 变更类型 | 必须更新 |
|----------|----------|
| 用户可见行为 | 使用说明 + README |
| 架构/打开路径 | 设计说明 |
| 版本发布 | 变更记录 + README 版本表 + manifest version |
| 权限模型 | 使用说明 + README + 商店权限话术 |
| 默认档位/TTL | CLAUDE 默认表 + README 四档表 |

## 3. 文风

- 中文为主；标识符保留英文  
- 先结论后展开；表格优先  
- 不写「保证秒开」等绝对化上架风险表述  
- 不在公开文档写用户要求保密的站点域名  

## 4. 版本号

`主.次.修订`，当前主线为 `0.5.x`。  
功能用户可见则升修订号，并记入 `docs/变更记录.md`。
