# Tech Melon XFaster 使用说明

**当前版本：0.5.28**

---

## 1. 这个扩展做什么？

帮助你从**其它网站**更快打开 **X（Twitter）** 链接：

- 后台最多保持 **1 个** X「热壳」标签  
- 点击 X 链接时优先 **复用** 该标签（或已打开的 X）  
- 尝试页面内拦截与 SPA 软跳；失败则整页导航到目标  
- **可选**：外站图片谷歌识图（Lens 小窗，与加速逻辑独立）  

**不是** X 客户端，**不**在 X 站内替换官方导航。

---

## 2. 安装

1. 打开 `chrome://extensions`  
2. 开启开发者模式  
3. 加载已解压目录，或解压 `dist/` 中对应版本 zip 后加载  
4. 建议固定到工具栏  

**重要：** 每次「重新加载」扩展后，请 **刷新** 已打开的网页，否则旧 content script 会失效（`Extension context invalidated`），表现为点不动或未拦截。

---

## 3. 推荐使用流程

1. 打开扩展弹窗  
2. 选择档位：**均衡**（默认）或 **极速**  
3. 若要在外站**无闪**拦截：点 **「一键授权所有网站」** → 浏览器权限框选允许  
4. 点 **「立即预热」**，或打开含 X 链接的页等待自动暖壳  
5. 看到 **壳已热** 后，在外站点 X 链接  
6. 不用时点 **「释放预热」** 释放内存  

### 授权说明

| 操作 | 效果 |
|------|------|
| 一键授权所有网站 | 一次授权；**现在 + 以后新开的 https 站** 均可页面内拦截 / 识图 |
| 授权当前网站 | 仅当前域名 |
| 不授权 | X 预热仍可用；外站可能「先冷开再合并热壳」；识图脚本也不会注入 |

授权后插件会尝试给**已打开**标签注入脚本；若某站仍异常，**刷新该站一次**。

---

## 4. 四档一键

| 档位 | 行为 | TTL 预设 |
|------|------|----------|
| 节能 | 不暖壳、少预连接 | 10 分钟 |
| 均衡 | 页面有 X 链接时暖 1 壳 | 20 分钟 |
| 快速 | 暖壳 + 悬停检测 | 30 分钟 |
| 极速 | 暖壳 + 悬停预热 | 45 分钟 |

设置页可改 TTL（1–60 分钟）。

---

## 4.1 谷歌识图（可选）

1. 先完成**全站或当前站授权**，并刷新目标网页  
2. 弹窗打开 **「谷歌识图」** 开关（默认关）  
3. 鼠标在图片上**大致静止**约 350ms（可在设置页改），图片会出现蓝色描边，**光标旁**出现较大的 **「搜图」** 按钮  
4. 移动光标时按钮不会马上消失；再次静止后按钮会跟到新位置。**默认点浮动「搜图」**（不拦截系统右键）  
5. 也可在系统右键菜单选 **「谷歌识图（XFaster）」**；或在设置里改成 Alt+右键 / 拦截右键等  
6. 结果默认 **小弹窗**（单例复用）；详细项见 **设置页 → 谷歌识图**  

**限制：**

- 仅支持可访问的 `http(s)` 图片地址；`blob:` / `data:` 暂不支持  
- 未授权的网站不会注入识图脚本  
- 排除域名列表中的站点：不拦截 X，也不识图

## 5. 权限说明

### 必需（安装即有）

- `storage` / `tabs` / `alarms` / `scripting` / `webNavigation` / `activeTab` / `windows` / `contextMenus`  
- 主机：`x.com`、`*.x.com`、`twitter.com`、`*.twitter.com`、`t.co`、`abs.twimg.com`、`api.x.com`、`api.twitter.com`  

### 可选（弹窗授权）

- `http://*/*`、`https://*/*`：外站完整拦截 + 识图能力  

**代码里没有写死第三方业务站白名单**；外站能力靠可选全站/当前站授权。

## 6. 常见问题

### 6.1 外站先弹出一个 X，再关掉，再进预热标签？

多半是 **未全站授权**，或 **授权后未刷新该外站**。

1. 弹窗确认 **全站已授权**  
2. 硬刷新外站  
3. 再点 X 链接  

### 6.2 没有 X 标签时同时出现 home + 推文？

0.5.18 起已禁止「先开 home 再开推文」。请使用 **≥0.5.18**。无标签时应 **只开目标 URL 一扇**。

### 6.3 X 站内主页/通知等点不动？

0.5.19 曾在站内误拦 `x.com` 链接。**0.5.20** 起在 X/Twitter **内不拦截**。请用 0.5.20 并 **硬刷新 x.com**。

### 6.4 重载扩展后链接点不动 / 控制台 Extension context invalidated？

旧 content script 已失效。请 **刷新该网页**。

### 6.5 弹窗一直「加载中」、授权按钮点不动？

多为 service worker 未启动或语法错误。请用 **≥0.5.17**，在 `chrome://extensions` 重新加载，关掉再开弹窗。

### 6.6 商店提示「所有网站的权限 / 深入审核」？

在 **0.5.11+** 下多为 **正常提示**（content 仍匹配全站 + optional 全网）。  
确认必需 host 已收窄后可直接 **提请审核**。详见商店 DOC 中的 `05-审核权限问题答复.md`。

---

## 7. 隐私

- 不要求扩展账号  
- 不上传浏览历史到开发者服务器  
- 设置与热壳状态在本地 `chrome.storage`  

---

## 8. 限制（诚实边界）

- 首次暖壳仍需正常加载时间  
- URL 完全不在 DOM、只在加密 API 里的按钮可能拦不到  
- SPA 软跳失败会整页导航（可能黑屏 logo 一瞬）  
- 扩展不能替代官方客户端全部能力
