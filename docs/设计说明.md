# Tech Melon XFaster 设计说明

**对应版本：0.5.34**

---

## 1. 问题

从外站打开 X 时常见路径是：新建标签 → 冷启动重 SPA → 数秒等待。  
目标：在可控内存下，用 **复用已加载壳 / 智能打开** 降低体感延迟。

---

## 2. 目标与非目标

**目标**

- 外站点击 X 相关 URL 时更快到达内容  
- 热壳单实例 + TTL，避免长期占满内存  
- 档位与站点授权可配置；商店审核可接受的权限模型  

**非目标**

- 替代官方 X 客户端  
- 24h 挂死完整 X  
- iframe / sidePanel 嵌 X  
- 后台轮询 timeline API  

---

## 3. 方案分层

| 级别 | 名称 | 行为 | 默认（均衡） |
|------|------|------|----------------|
| L0 | 冷 | 无 | — |
| L1 | 连接热 | preconnect 少量关键域 | 开 |
| L2 | 意图热 | 悬停检测 | 关 |
| L3 | 实例热 | 最多 1 个后台/复用 X 标签 + TTL | 有链接时自动暖 |

### 打开路径（0.5.18+）

```text
点击 X URL
  → 规范化 URL（剥 /photo、追踪参数；status id 对齐）
  → 若有可复用 X 标签：
        冻结 / 丢弃 / 未加载
          → 同标签 tabs.update(目标)（不关标签、不新开第二扇）
        否则 → SPA 软跳（对齐 0.5.31：地址对上即可）
          → 成功后再核对 URL，回退到旧帖则整页
          → 地址已在目标则不要 reload 冲掉绘制中的 SPA
  → 若无任何 X 标签：
        只 create 目标 URL 一次（禁止先 create home）
  → 全局创建锁，防止与「立即预热」并发双开
```

### 外站拦截（需可选全站权限才完整）

```text
document_start MAIN：
  - 非 X 站：hook window.open / a.click / a[target=_blank]→X
  - X 站：不 hook（0.5.20）

ISOLATED link-observer：
  - 非 X 站：pointerdown/click 解析 href 与伪链接 → OPEN_X
  - X 站：不初始化（0.5.20）

兜底：webNavigation / tabs 捕获冷开的 X 标签 → 合并热壳
```

## 5. 权限模型（0.5.11+）

| 类型 | 内容 |
|------|------|
| 必需 host | 仅 X/Twitter/t.co/twimg/api |
| optional host | 全网 http(s)；弹窗用户自愿授权 |
| activeTab | 用户手势辅助 |

**商店：** 内容脚本仍可声明匹配全站，但 **必需 host 不含 `*://*/*`**，减少「所有网站必需权限」拒审风险；黄条「深入审核」仍可能出现（content 全站匹配 / optional 全网），属常见情况。

## 6. 热壳生命周期

```text
立即预热 / 页面有链接自动暖（均衡+）
  → 有可复用 X：登记为热壳
  → 否则 create(entryUrl, active:false)  // 仅预热路径
  → expireAt = now + TTL；alarms

打开推文
  → 复用热壳/已有 X，导航到目标（不先 create home）

TTL 到期
  → 后台热标签：remove 并清理 warmState
  → 前台正在看：不关标签，下次外站打开仍先 SPA

冻结 / 丢弃
  → 不关标签，同标签整页打开目标 URL

X 把 SPA 地址改回旧帖
  → 同标签整页打开目标 URL

用户关闭标签
  → onRemoved 清理
```

TTL 用 **绝对时间戳**。

## 7. 四档

| 档位 | L1 | L2 | 自动 L3 | 默认 TTL |
|------|----|----|---------|----------|
| eco | ✗ | ✗ | ✗ | 10m |
| balanced | ✓ | ✗ | 有链接 | 30m |
| fast | ✓ | ✓ | 有链接 | 45m |
| turbo | ✓ | ✓ | 有链接+悬停 | 60m |

## 8. 关键纪律

1. **KISS**：只做打开加速与可控预热  
2. **X 站内永不拦截**用户导航（侧栏/站内 a）  
3. **打开推文禁止先开 home**  
4. **真 SPA** 才算成功；假成功必须整页回退  
5. **单实例 + TTL**  
6. **壳不可信不关标签**：冻结/丢弃/URL 回退时同标签整页打开目标  
7. **注释中禁止出现会提前结束块注释的 `*/` 序列**（如错误的 URL 注释）  
8. 改权限必须同步 README / 使用说明 / 商店话术  

---

## 9. 风险与边界

- L3 内存大：靠 TTL、释放、档位  
- 外站未授权：只能事后合并，可能闪冷标签  
- DOM 无 URL 的按钮：无法页面内拦截  
- SPA 失败：整页加载，可能黑屏 logo
