# Tech Melon XFaster

从任意网页更快打开 **X（Twitter）** 的 Chrome 扩展（Manifest V3）。  
**出品：Tech Melon（技术瓜）**

当前版本：**0.5.28**

---

## 功能概览

| 能力 | 说明 |
|------|------|
| 热壳复用 | 最多 1 个 X 标签预热，减少冷启动 |
| 智能打开 | 优先复用已打开/预热标签；无标签时只开目标 URL（不双开 home+推文） |
| 外站拦截 | 拦截 `a[href]`、`target=_blank`、`window.open`、程序化 `a.click()`、部分伪链接 |
| 导航捕获 | 外站仍冷开时，合并到热壳（兜底） |
| 四档一键 | 节能 / 均衡 / 快速 / 极速（弹窗） |
| 站点授权 | 弹窗「一键授权所有网站 / 授权当前站」；授权后自动注入已开标签 |
| X 站内安全 | **在 x.com / twitter.com 内不拦截**，侧栏导航保持正常 |
| 谷歌识图 | **可选**：鼠标在图上静止后键鼠触发；Lens 小窗/新标签；弹窗一键开关，细节在设置页 |

## 四档配置

| 档位 | 自动暖壳 | 悬停 | TTL 预设 |
|------|----------|------|----------|
| 节能 | 否 | 否 | 10 分钟 |
| **均衡（默认）** | 有链接时 | 否 | 20 分钟 |
| 快速 | 有链接时 | 检测 | 30 分钟 |
| 极速 | 有链接时 | 预热 | 45 分钟 |

TTL 可在设置中选 1–60 分钟（最大 1 小时）。

## 权限模型（商店友好）

| 类型 | 内容 |
|------|------|
| **必需 host** | 仅 X 相关：`x.com`、`twitter.com`、`t.co`、`abs.twimg.com`、`api.x.com`、`api.twitter.com` |
| **可选 host** | `http://*/*`、`https://*/*`（用户弹窗自愿授权） |
| **其它** | `storage`、`tabs`、`alarms`、`scripting`、`webNavigation`、`activeTab` |

- **未授权全站**：X 预热/复用仍可用；外站可能先冷开再合并热壳（可能闪一下）  
- **已授权全站**：外站页面内拦截，体验接近完整权限；**以后新开的未知站也生效**  
- **X 站内**：不注入外站拦截逻辑，避免侧栏点不动

## 安装（开发）

1. `chrome://extensions` → 开发者模式  
2. 「加载已解压的扩展程序」→ 选本仓库根目录，或解压：

```text
dist/TechMelon-XFaster-0.5.20.zip
```

3. **重载扩展后请刷新已打开的网页**（否则可能 `Extension context invalidated`）

### 推荐使用步骤

1. 弹窗选 **均衡** 或 **极速**  
2. 点 **一键授权所有网站**（若要在外站无闪拦截）  
3. **立即预热** 或打开含 X 链接的页等待暖壳  
4. 在外站点 X 链接  
5. 不用时 **释放预热**
